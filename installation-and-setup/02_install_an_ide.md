# How to Install VS Code


## Windows

### Step 1: Download
1. Go to [https://code.visualstudio.com/]
2. Click on the button: **Download for Windows**

### Step 2: Installation
1. Open the installer file (.exe)
2. Accept the agreement and click **"Next"**
3. Select the destination folder (leave default) and click **"Next"**
4. **IMPORTANT:** Check these boxes:
   - **Add "Open with Code" action to Windows Explorer file context menu**
   - **Add "Open with Code" action to Windows Explorer directory context menu**
   - **Add to PATH**

5. Click **"Next"** and then **"Install"**

### Step 3: Verification
1. Open VS Code
2. You should see the welcome screen

---

## Mac

### Step 1: Download
1. Go to [https://code.visualstudio.com/] 
2. Click on the button: **Download for Mac**

### Step 2: Installation
1. Open the downloaded file (.zip)
2. Drag **Visual Studio Code.app** to the **Applications** folder

### Step 3: Verification
1. Open VS Code from the Applications folder
2. You should see the welcome screen
